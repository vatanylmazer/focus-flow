🍅 Focus Flow (Pomodoro Timer & Task Manager)

A modern, sleek productivity web application built to boost focus using the Pomodoro technique, integrated with local task management.

🚀 Features
- Fully functional 25-minute countdown timer with start, pause, and reset controls.
- Dynamic task manager to track session goals.
- Task completion toggle and local storage persistence.
- Sleek glassmorphism and dark mode design.

🛠️ Built With
- HTML5
- CSS3 (Flexbox, Backdrop Filter effects)
- JavaScript (Interval timers, DOM manipulation, LocalStorage API)

⚙️ Setup & Run
1. Clone this repository to your local machine.
2. Open `index.html` in your browser or run it via Live Server.
